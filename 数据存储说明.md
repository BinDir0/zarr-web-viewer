# 数据存储说明

## 📁 标注数据存储位置

**数据库文件**: `/home/guantianrui/zarr-viewer/annotations.db`

这是一个 SQLite 数据库文件，包含以下表：

### 1. `annotations` 表 - 备注内容

存储每个 episode 的备注文本，包含完整的元数据。

```sql
CREATE TABLE annotations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    episode_id TEXT NOT NULL UNIQUE,   -- 例如: "EgoDex::1234"
    episode_name TEXT,                 -- episode名称
    dataset_name TEXT,                 -- 数据集名称
    episode_index INTEGER,             -- 在数据集中的索引位置
    content TEXT NOT NULL,             -- 备注内容
    updated_at TEXT NOT NULL           -- 最后更新时间
);
```

**示例数据**:
```
episode_id: "EgoDex::1234"
episode_name: "extra_assemble_disassemble_jigsaw_puzzle_10"
dataset_name: "EgoDex"
episode_index: 1234
content: "这个episode质量很好，手部动作清晰"
updated_at: "2026-01-30T15:30:00"
```

**字段说明**:
- `episode_id`: 唯一标识符，格式为 "数据集名::索引"
- `episode_name`: episode 的原始名称，便于查找和识别
- `dataset_name`: 所属数据集名称
- `episode_index`: 在该数据集中的索引位置（第几个episode）
- `content`: 用户输入的备注内容
- `updated_at`: 最后更新时间（UTC）

### 2. `view_log` 表 - 查看记录

记录谁查看了哪个 episode（用于多人协作防冲突）。

```sql
CREATE TABLE view_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    episode_id TEXT NOT NULL,          -- 例如: "EgoDex::1234"
    user_id TEXT NOT NULL,             -- 例如: "user_1738245600_abc123"
    viewed_at TEXT NOT NULL,           -- 查看时间
    UNIQUE(episode_id, user_id)        -- 同一用户同一episode只记录一次
);
```

**示例数据**:
```
episode_id: "EgoDex::1234"
user_id: "user_1738245600_abc123"
viewed_at: "2026-01-30T15:30:00"
```

## 🔍 查看数据库内容

### 使用 SQLite 命令行工具

```bash
cd /home/guantianrui/zarr-viewer

# 查看所有备注（包含完整信息）
sqlite3 annotations.db "SELECT episode_id, episode_name, dataset_name, episode_index, content FROM annotations;"

# 查看某个数据集的所有备注
sqlite3 annotations.db "SELECT * FROM annotations WHERE dataset_name='EgoDex';"

# 按数据集统计备注数量
sqlite3 annotations.db "SELECT dataset_name, COUNT(*) as count FROM annotations GROUP BY dataset_name;"

# 查看查看记录统计
sqlite3 annotations.db "SELECT user_id, COUNT(*) as view_count FROM view_log GROUP BY user_id;"

# 查看某个用户的所有查看记录
sqlite3 annotations.db "SELECT * FROM view_log WHERE user_id='user_xxx';"

# 导出备注数据为 CSV（包含所有字段）
sqlite3 annotations.db -csv -header "SELECT episode_id, episode_name, dataset_name, episode_index, content, updated_at FROM annotations;" > annotations.csv
```

### 使用 Python 脚本

```python
import sqlite3

conn = sqlite3.connect('/home/guantianrui/zarr-viewer/annotations.db')
cursor = conn.cursor()

# 查看所有备注
cursor.execute("SELECT * FROM annotations")
for row in cursor.fetchall():
    print(row)

# 统计
cursor.execute("SELECT COUNT(*) FROM annotations")
print(f"总备注数: {cursor.fetchone()[0]}")

cursor.execute("SELECT COUNT(DISTINCT episode_id) FROM view_log")
print(f"已查看的episodes数: {cursor.fetchone()[0]}")

conn.close()
```

```bash

```

## 📈 数据量估算

- 每条备注记录: 约 100-500 字节（取决于备注长度）
- 每条查看记录: 约 100 字节
- 预估 100万 episodes × 平均30%被查看 = 30万条记录
- 数据库大小: 约 50-100 MB

## 🛠️ 清理数据

### 清除所有查看记录（重置）

```sql
DELETE FROM view_log;
```

### 清除某个用户的查看记录

```sql
DELETE FROM view_log WHERE user_id = 'user_xxx';
```

### 清除所有备注

```sql
DELETE FROM annotations;
```

**注意**: 清除前请先备份！

## 🔒 数据安全

1. **定期备份**: 建议每天备份一次数据库
2. **权限控制**: 确保只有授权用户能访问数据库文件
3. **并发访问**: SQLite 支持多读单写，适合小团队使用
4. **如果团队很大**: 考虑迁移到 PostgreSQL 或 MySQL

## 📝 数据导出

### 导出备注为 JSON

```python
import sqlite3
import json

conn = sqlite3.connect('annotations.db')
cursor = conn.cursor()

cursor.execute("SELECT episode_id, content, updated_at FROM annotations")
annotations = [
    {
        "episode_id": row[0],
        "content": row[1],
        "updated_at": row[2]
    }
    for row in cursor.fetchall()
]

with open('annotations_export.json', 'w', encoding='utf-8') as f:
    json.dump(annotations, f, ensure_ascii=False, indent=2)

print(f"导出了 {len(annotations)} 条备注")
```

### 导出查看记录统计

```python
import sqlite3
import pandas as pd

conn = sqlite3.connect('annotations.db')

# 导出为 DataFrame
df = pd.read_sql_query("""
    SELECT 
        v.episode_id,
        v.user_id,
        v.viewed_at,
        a.content as annotation
    FROM view_log v
    LEFT JOIN annotations a ON v.episode_id = a.episode_id
""", conn)

# 保存为 Excel
df.to_excel('view_log_export.xlsx', index=False)

conn.close()
```
